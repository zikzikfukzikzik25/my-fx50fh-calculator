Scientific Calculator — local copy

This package is based on the uploaded fx-50FH II Web Edition source.
The original MIT LICENSE is included; keep it with the source when modifying
or redistributing. The license does not cover the CASIO product photograph
assets/fx-50fh-ii.png.

To run:
1. Unzip this folder.
2. In Terminal, cd into the extracted fx-50fh-ii-main folder.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000 in your browser.

Do not open index.html directly as file://; ES modules may not load.
